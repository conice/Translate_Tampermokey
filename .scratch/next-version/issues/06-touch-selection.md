# 06: 触屏取词:44px、滚动跟随、400 字跨行

**What to build:** 手机上译气泡有足够大的点击面积;滚动页面时气泡跟着选区走而不是直接消失,只有选区完全滚出视口才收起;拖选一段跨行的文字(不超过 400 字符)也能出气泡并查询。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 气泡可见尺寸提到 44×44,字号同比微调,圆角保持圆形
- [x] 气泡提供更新位置的能力,由页面滚动驱动,按每帧最多一次节流
- [x] 滚动时气泡重定位到当前的选区位置;只有选区完全离开视口时才隐藏
- [x] 触屏端滚动时释义浮窗关闭;桌面端滚动时浮窗保持打开且位置不变
- [x] 触屏取词上限从 120 字符放宽到 400 字符
- [x] 触屏端允许含换行的选区出气泡(句子模式由 03 承接)
- [x] 桌面双击取词路径的现有上限与行为不变
- [x] 打包产物冒烟测试覆盖:气泡尺寸为 44;滚动后气泡定位被更新而不是被隐藏;跨行且 400 字符内的选区出气泡
- [x] README 手测清单补一条:真机上滚动时气泡跟随、选跨行段落能出气泡

## Comments

**实现**

- `src/core/gesture.js`
  - `MAX_BUBBLE_CHARS` 从 120 提到 400 并导出。它现在是「一次查询的上限」而不是「一个词条的上限」:手机上拖选一句话,和桌面上选中一句话是同一件事,03 的句子模式已经能承接。
  - 删掉「含换行就当复制手势」那条规则。跨行拖选照样出气泡。
  - `selectionTerm` 改用 `normalizeSentence`。这补上了 03 留下的缺口:之前触屏送进翻译源的是小写文本,句子模式的译文因此会丢失大小写。
  - 新增纯函数 `isRectVisible(rect, viewport)`:只有选区**完全**离开视口才为 false,压在边缘上仍算可见。
- `src/ui/bubble.js`
  - 尺寸 40 → 44(圆角用 `50%` 而不是写死的 `20px`,放大后仍是正圆),字号 15 → 16。`BUBBLE_SIZE` 只写一处,同时供样式表和定位计算使用。
  - 定位逻辑抽成 `place()`,`show(rect)` 与新增的 `reposition(rect)` 共用。隐藏状态下 `reposition` 是空操作;传入空 rect 时沿用上一个位置,不让一次瞬时布局空洞把气泡甩走。
  - 新增只读的 `visible`。
- `src/main.js`
  - 触屏的滚动监听从「直接 `bubble.hide()`」改成 `onScroll`:`requestAnimationFrame` 节流,每帧最多重定位一次;`followSelection()` 读取当前选区矩形,可见就 `reposition`,完全出屏才 `hide`。
  - 触屏滚动同时关闭释义浮窗。桌面端**不注册**滚动监听,所以浮窗保持打开、位置不变(两条都有测试)。
  - 顺手修了一个 `selectionTerm` 改动的连带问题:`evaluateSelection` 里「浮窗已经在查这个词,就别再冒气泡」的判断原本只比较原文,而浮窗里存的是归一化词形;现在两种写法都比。

**测试**

- `test/gesture.test.mjs`:跨行选区出气泡、400/401 边界、`selectionTerm` 保留大小写与换行、`isRectVisible` 的六个方位与缺字段情形。原「多行/超长不出气泡」那条按新行为改写。
- `test/userscript.smoke.test.mjs`:44px(用 `getComputedStyle` 读影子根内的样式,jsdom 支持)、滚动后气泡跟随、滚出视口后收起、触屏滚动关浮窗、桌面滚动不关浮窗、跨行选区出气泡并查询。原来的「滚动就收气泡」「多行不出气泡」两条按新行为改写。

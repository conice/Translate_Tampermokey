## Comments

**版本**

- `package.json` → `0.3.0`。
- `build.mjs` 不再手写版本号,改为从 `package.json` 读。这是本次唯一一处「顺手改结构」:上一版两个文件分别是 0.2.0 与 0.1.0,靠人记住改两处不可能长期成立。
- 冒烟测试新增一条:构建产物的 `@version` 必须等于 `package.json` 的 `version`。以后再发版,漏改一处会直接测试失败。

**ADR-0007**

`docs/adr/0007-touch-selection-limit-and-multiline.md`。只写 06 的两条决策(上限 400、允许跨行),显式声明桌面/触屏的分工、「点了才查」的语义、共用查询流程均沿用 ADR-0006,不重复论证。记了三条被拒的替代方案,以及代价(跨行选区也可能是复制的前奏,由「必须点气泡」兜住)。

**README**

- 「使用」表:补句子查询、复制译文、超限提示、深色模式;触屏取词一行写明 44px、可跨行、≤400 字符、滚动跟随。
- 设计要点:补主题变量与真人发音两条,句子模式那条保留。
- 验证段拆成「自动测试」与「真机手测清单」两块,后者是 8 条可勾选项 —— 触屏取词、气泡大小与滚动、跨行选区、超限提示、句子模式、深色模式、发音(含 iOS)、注音可读性。
- 已知限制:删掉「注音颜色固定灰」「关闭注音会调用整页 normalize」这类本版已修的内容,补三条仍存在的 —— 站点用更高优先级 `!important` 或内联样式覆盖注音、浮层跟随系统而非宿主页面主题、关闭注音后含元素子节点的段落会留下相邻文本节点。

**一处一致性修补**

写 ADR 时发现:03 的超限提示只接在桌面双击路径上,触屏端选超 400 字符仍然「什么都不发生」,与 spec 里「不再静默」的用户故事不符,也和我写进 ADR 的说法矛盾。已补:`evaluateSelection` 在拒绝气泡时,若选区来自页面正文(不是我们自己的 UI、也不是输入框)且超长,同样显示提示。冒烟测试加了一条。

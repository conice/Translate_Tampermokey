# 04: 注音可读性

**What to build:** 注音在深色正文、彩色小标题、白字黑底这类站点上都能读出来,因为它的颜色跟随所在文字的颜色,而不是固定灰;站点的全局样式也不会把注音的字号、颜色或排版改掉。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 注音颜色改为跟随宿主文字颜色并降低不透明度,在浅色与深色页面上都能读;浏览器不支持颜色混算时有回退方案
- [ ] 括号、字号、左右边距、不换行、不可选中这些排版属性保持显式设定
- [ ] 关键属性(字号、颜色、边距、不换行、不可选中、指针样式)全部带 `!important`,类名不变
- [ ] 现有注音 DOM 测试全部保持通过(幂等、跳过代码块与可编辑区、嵌套容器不重复处理)
- [ ] 新增测试:注入的样式规则对关键属性带 `!important`
- [ ] 该样式仍然只注入一次,不随刷新重复添加

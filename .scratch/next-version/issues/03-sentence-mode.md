# 03: 句子模式与超限提示

**What to build:** 选中一句话查询时,译文保留原有大小写与分段,浮窗只给译文、复制、发音和关闭,不请求词典、不显示收藏区;选中的文本超过 400 字符时,选区旁浮出一句短暂提示,而不是毫无反应。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增一条只整理空白的文本路径:折叠内部连续空白、去首尾空白、保留大小写与换行;它有单元测试,并与现有的归一化路径互不影响
- [ ] 查询流程按「是否可作为词条」(不超过 40 字符且不超过 5 个词)分流:词条模式行为不变,句子模式走新路径
- [ ] 句子模式的译文中保留大小写与换行,不再被转成小写或压成一行
- [ ] 句子模式不请求词典、不计算原形、不显示「加入生词本」和「过长,仅可查看」
- [ ] 超过 40 字符但不超过 400 字符的选区,浮窗显示译文、复制、发音、关闭四项
- [ ] 词条模式也提供「复制译文」
- [ ] 复制失败(例如站点拒绝剪贴板权限)时不报错、不影响其他操作
- [ ] 选区超过 400 字符时,在选区旁显示一句「最多 400 字」,2 秒后自动消失,复用现有的放置逻辑
- [ ] 打包产物冒烟测试覆盖:41 字符选区只出现译文相关控件且没有词典请求;超 400 字符选区出现提示
- [ ] 现有词条模式的测试全部保持通过

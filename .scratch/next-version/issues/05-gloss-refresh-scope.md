# 05: 注音刷新的清理范围

**What to build:** 关掉本站注音、或生词本变化触发刷新之后,页面完全恢复成原文,且不会因为清理而把整页的文本节点合并掉;在依赖节点身份的框架渲染页面上开关注音,内容不会错位或丢失。

**Blocked by:** 04 (改的是同一处注音样式与标记的清理逻辑)

**Status:** ready-for-agent

- [ ] 刷新注音时不再调用整页的文本节点合并
- [ ] 每个注音标记被换回它自己的原始文本,而不是被注音后的拼接文本替换
- [ ] 只有当父节点的子节点全部是文本节点时才在该父节点上做合并,父节点含元素子节点时保持不动
- [ ] 关闭本站注音后,页面文本与开启前完全一致,不残留标记元素或空标签
- [ ] 反复开启/关闭注音不会让文本节点数量无限增长
- [ ] 新增 DOM 测试:父节点含元素子节点时不被合并;只在文本节点之间合并时,合并范围不越出该父节点
- [ ] 现有注音 DOM 测试全部保持通过

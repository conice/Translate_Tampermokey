# 02: 真人发音

**What to build:** 点释义浮窗的发音按钮,优先播放词典源提供的真人录音(美音优先,其次英音,再次任一可用录音);正在播放时再点一次停止;录音取不到、被页面策略挡住或播放失败时,静默回退到现有的系统 TTS,按钮仍然只有一个,不出现错误提示。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 词典解析出的音频地址不再被丢弃,一路传到浮窗的渲染状态里
- [ ] 选音是纯函数:在多个录音中按美音、英音、任一非空的顺序挑一个;没有录音时返回空;该函数有单元测试覆盖「只有美音」「只有英音」「只有其他口音」「一个都没有」四种情况
- [ ] 音频请求走一个与现有文本请求并列的可注入依赖,使用用户脚本管理器的二进制响应模式;音频域名与词典接口同域,元数据的域名白名单不需要新增条目
- [ ] 播放中的再次点击会停止当前播放,不会叠着播
- [ ] 播放结束或出错时释放创建的临时对象地址,不泄漏
- [ ] 没有录音、取录音失败、播放失败三种情况都回退到系统 TTS,且不弹任何错误
- [ ] 音频地址不写进词条,不改动生词本的数据结构
- [ ] 打包产物冒烟测试覆盖:词典响应带音频 → 发出音频请求并播放;词典响应不带音频 → 不发出音频请求,直接走 TTS
- [ ] README 手测清单补一条:真机点发音按钮能出声

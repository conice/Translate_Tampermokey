## Comments

检查中修掉的三处:

1. **全逗号行被当成空行丢弃。** `,,,` 原本被 CSV 解析器过滤掉,导致一行坏数据既不导入也不计入「跳过」。现在只有真正的空白行被丢弃。
2. **覆盖模式可以清空生词本。** 选一个只有表头(或内容全坏)的文件并点「覆盖现有」,会先清空再导入 0 条。现在这种文件直接报错并保留现有生词本 —— ADR-0008 承诺的「拿错文件不会清空」此前只覆盖了「表头不对」,没覆盖「表头对但没有可用行」。
3. **`hidden` 藏不住面板里的行。** 导入时出现的选择行带有 `.row` 类,而 `.row { display: flex }` 是作者样式,按层叠规则压过 UA 样式表的 `[hidden] { display: none }`。结果是「现有 N 条…覆盖/合并/取消」常驻在设置页。已在面板样式表里补 `[hidden] { display: none !important; }`,并加测试钉住这条规则。原来的「确认导入」按钮(`button.small` 带 `all: unset`)也有同样的问题,只是被这次改动替换掉了。

同时补上了:README 的真机清单五条、已知限制三条(`showSaveFilePicker` 的适用范围、取消选择不触发 `cancel` 的极端情况、不能回退)、ADR-0009 的回退说明;以及一条「导入失败时面板显示原因并收起提示」的 DOM 测试。

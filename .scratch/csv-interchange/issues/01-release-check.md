## Comments

检查中修掉的三处:

1. **全逗号行被当成空行丢弃。** `,,,` 原本被 CSV 解析器过滤掉,导致一行坏数据既不导入也不计入「跳过」。现在只有真正的空白行被丢弃。
2. **覆盖模式可以清空生词本。** 选一个只有表头(或内容全坏)的文件并点「覆盖现有」,会先清空再导入 0 条。现在这种文件直接报错并保留现有生词本 —— ADR-0008 承诺的「拿错文件不会清空」此前只覆盖了「表头不对」,没覆盖「表头对但没有可用行」。
3. **`hidden` 藏不住面板里的行。** 导入时出现的选择行带有 `.row` 类,而 `.row { display: flex }` 是作者样式,按层叠规则压过 UA 样式表的 `[hidden] { display: none }`。结果是「现有 N 条…覆盖/合并/取消」常驻在设置页。已在面板样式表里补 `[hidden] { display: none !important; }`,并加测试钉住这条规则。原来的「确认导入」按钮(`button.small` 带 `all: unset`)也有同样的问题,只是被这次改动替换掉了。

同时补上了:README 的真机清单五条、已知限制三条(`showSaveFilePicker` 的适用范围、取消选择不触发 `cancel` 的极端情况、不能回退)、ADR-0009 的回退说明;以及一条「导入失败时面板显示原因并收起提示」的 DOM 测试。

### 发布后复审

0.4.0 发布后对这批改动做了一轮独立复审,以下按严重程度修复(均有测试):

1. **导出单元格可被表格软件当公式执行。** 词条内容来自任意网页,`=cmd|...` 之类会落到 CSV 里。现在只有给人看的导出文件给 `= + - @` 开头的单元格加 `'` 前缀,导入时再剥掉;本机存储不加,因为它只被本脚本读取。
2. **`addedAt` 超出 `Date` 范围会让每次保存都抛错。** 原实现只检查 `Number.isFinite`,而 `new Date(1e20).toISOString()` 会抛 `RangeError`;错误又被存储适配器吞掉,表现为「导入成功但刷新后消失」。现在导入与导出都按 `|t| <= 8.64e15` 校验。
3. **`normalized` 列可伪造词条身份。** 手改文件里的 `normalized=Running` 会生成 `en|Running`,而查询流程只产生 `en|running`,该词永远不会被注音。现在身份一律由词面重新 `normalizeTerm` 得出。
4. **保存对话框选好路径后写失败会静默改走下载。** 文件可能落到别处。现在只有「选择器根本没打开」才退回下载,拿到句柄后的写入/关闭失败直接报给面板。
5. **不派发 `cancel` 的浏览器会让导入永远挂起**,隐藏 `<input>` 也不会回收。现在页面重新获得焦点后 1 秒检查文件列表,未选文件即当作取消。
6. **缓存行的 `expires` 是 `NaN` 时永不淘汰**(`NaN <= now` 为 `false`)。读取时丢弃这种行。
7. **存储写入失败被当作成功。** 适配器现在返回是否写入;导入时写失败会明确报错,而不是显示「导入 N 条」。
8. **面板的 `::-webkit-scrollbar` 规则是死代码**:Chromium 121+ 在设置 `scrollbar-width` 后会忽略这些伪元素。规则移进 `@supports not (scrollbar-width: thin)`,只服务旧 WebKit。
9. **文档说错了升级路径。** 0.3.x 只有 JSON 文本导出,没有 CSV,「升级前先导出 CSV」做不到;升级本身无需准备(旧 JSON 自动迁移),要留后路应在升级后用 0.4.0 导出。README、ADR-0009 与本文件已改正。
